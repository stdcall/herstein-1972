# Сборка и соглашения

Требуются Typst 0.15.1, Typstyle 0.15.1, Tinymist 0.15.8, Python 3.14,
uv и just. Шрифты с лицензиями находятся в `assets/fonts`.

`just build` собирает книгу; `just corrections` — список исправлений;
`just build-no-notes` — вариант без редакционных примечаний.
`just check` проверяет исходники, ссылки, шрифты и все варианты PDF.
Машинные настройки задаются в `.env`.

## Исходники

Каждый раздел — обычная разметка в `content/CS-slug.typ`:
`10-jacobson-radical.typ` открывает главу, `11-modules.typ` содержит
§ 1.1, `12-radical.typ` — § 1.2. Главы включаются в `main.typ`.
В главах нет локальных правил вёрстки, ручных отступов, переносов формул
ради ширины строки, обёрток для предпросмотра или вычисляемых меток.
Строки форматируются Typstyle до 80 символов.

Заголовки — `= Радикал Джекобсона <ch:jacobson-radical>` и
`== Модули <sec:modules>`, без набранных номеров. Нумерация глав и
параграфов вычисляется счётчиком Typst.

Теоремы и леммы имеют раздельные счётчики внутри параграфа:
`#theorem[…] <th:schur>` и `#lemma[…] <lem:annihilator-ideal>`.
Шапки печатают полные номера вида 1.1.1. Определения без номера:
`#definition[…]`. Следствия обычно без номера: `#corollary[…]`.
Определения набраны прямым текстом; определяемый термин выделяется
курсивом. Нативные нумерованные списки используют маркеры `(1)`.
Два нумерованных примера § 1.4 задаются окружением
`#example-item[…] <exm:semantic-name>`; его счётчик и ссылки
`@exm:semantic-name[]` вычисляют номер примера.
Доказательства — `#proof[…]`; `qed: false` сохраняет отсутствие
заключительного знака, если оно существенно для непрерывного рассуждения.
Никаких номеров в аргументах окружений нет.
Локальные формулы доказательства задаются `#proof(equations: [@lem:…])[…]`.
Ссылка внутри того же доказательства печатает локальный номер; снаружи
он включает номер утверждения.

Формулы без метки не нумеруются. Метка `<eq:semantic-name>` после
выключной формулы включает её автоматический номер. Перед присвоением
метки надо проверить, есть ли номер в печатном издании.
Ненумерованный объект, к которому нужна ссылка, получает метку своей
семантической семьи; его описательная ссылка содержит текст явно.
Общий стиль уменьшает умеренно широкую выключную формулу до ширины
полосы; размер её номера сохраняется. Длинные ненумерованные вычисления
переносятся нативным абзацем с обычным размером математического шрифта.
Вводный абзац утверждения остаётся
с первой выключной формулой, а формула — со следующим текстом утверждения.

Матрицы из чисел и одиночных букв с отрицательными элементами получают
правое выравнивание столбцов общим правилом в `book-style.typ`.

Ссылки — нативные `@th:schur`, внутри формул `#[@th:schur]`.
Имена меток смысловые, стабильные, написаны буквально после цели.
Слова «теорема», «лемма», «§» остаются в прозе, полужирным выделяется
только вычисляемый номер: `теорема~@th:schur`.
Индексы функций отделяются от внешнего аргумента: `f_i lr((x))`.
Неразрывные сокращения: `т.~е.`, `т.~д.`, `т.~п.`.

`#source(N)` — невидимая отметка границы страницы исходного издания;
она стоит перед словом, не разрывает предложение и не управляет вёрсткой.
Номер физического листа и печатный номер различаются; отметка сама
не участвует в печатной пагинации.

## Литература и указатели

Все описания хранятся только в `references.bib`, ключи вида
`Jacobson1964`, `Amitsur1954a`. Для русского перевода добавляется `Ru`:
`JacobsonRu1961`. У книг, упомянутых в предисловии без года и указания
издания, ключ содержит фамилию и отличительное слово заглавия;
неизвестные выходные данные не дополняются предположениями.
Составные записи связываются через
`related`; описания создаёт `bibliography-style.typ` по полям `.bib`.
Поле `annotation` может задавать шаблон с подстановками полей, но
не повторяет их значения. DOI хранится только после сверки с публикацией.
Неподтверждённые язык и сокращение журнала не угадываются.

Авторские списки литературы объединяются в один список после основного
текста; повторяющиеся публикации представлены один раз. Ссылки из
глав используют семантические ключи `@bib:AuthorYear`; номера списка
вычисляются при сборке. В списках при главах `#chapter-bibliography[…]`
выводит для каждой нативной ссылки автора, название, год и номер полной
записи; поля берутся из `.bib`. Обзорные абзацы разделов «Литература»
остаются при соответствующих главах. Звёздочка у добавленных переводчиком
работ сохраняется в записи и поясняется в списке.
Список страниц упоминаний у каждой записи ведёт к ссылкам в тексте;
ссылки между записями самой библиографии в этот список не входят.

Предметный и именной указатели генерируются из отметок рядом с текстом.
`#idx("Модуль", "точный")` отмечает термин; для именованного объекта
цель задаётся его смысловой меткой. Номера страниц вычисляются по месту
назначения, а не по положению поздней отметки.

Исправления печатного текста записываются в `corrections.json` с
исходным чтением, исправлением и обоснованием. Простые исправления
не требуют примечания. Существенное редакционное дополнение —
`#ed-note[…]`; его литература находится в `editorial.bib`.

## Пагинация

Обложка вне счёта. Английский титул принят за страницу 2, русский
титул — за 3, аннотация — за 4; их номера скрыты.
Предисловие редактора перевода начинается со страницы 5. В этой вёрстке
перед авторским предисловием добавлен пустой оборот со скрытым номером 6.
Авторское предисловие начинается со страницы 7. Арабский счёт
продолжается в основном тексте и указателях без сброса.
Пагинация основного текста меняется при перевёрстке; оглавление,
указатели и ссылки всегда используют номера этой версии.

## Проверки и изменения

Метки и нумерацию проверяет `just check`; редактор использует нативные
ссылки и Tinymist lock database. Новые шрифты добавляются только с
лицензиями. PDF проверяются на посторонние шрифты и отсутствующие глифы.
Проверки математики находятся в `checks/`; их охват и ограничения
указываются явно. Изменения выполняются через pull request со слиянием
squash после успешных проверок CI.
