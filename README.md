# Некоммутативные кольца

И. Херстейн. *Некоммутативные кольца*. Перевод с английского
Е. Н. Кузьмина под редакцией А. И. Ширшова. Москва: Мир, 1972.

Книга вводит в структурную теорию ассоциативных колец: радикал
Джекобсона, полупростые кольца, теоремы коммутативности, простые алгебры,
представления конечных групп, полиномиальные тождества, теоремы Голди
и Голода — Шафаревича.

Текст набран в Typst. Ссылки, оглавление и указатели вычисляются
при сборке. Список подтверждённых исправлений выпускается отдельным PDF.
Команды сборки и соглашения исходников описаны в `CONTRIBUTING.md`.
